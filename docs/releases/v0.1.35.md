English translation test build for **Summon Night 3** on PSP, Japanese release
**NPJH50380**. This is an incomplete fan translation with identified story and
battle-dialogue resources through Chapter 8 and ongoing interface work.

### Apply

**Desktop patcher:** [Retro Trans](https://github.com/retro-trans/retro-trans-tools),
using manual **Apply xdelta** mode. Select your original ISO, the patch and a
new output filename. Automatic catalog detection has not been verified.

**Other ways:** [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher)
accepts the same `.xdelta` file. Keep checksum verification enabled.

**Command line:** use [xdelta3](https://github.com/jmacd/xdelta):

| Your source image | Patch |
|---|---|
| Clean Japanese PSP ISO, NPJH50380 | `SN3-English-v0.1.35.xdelta` |

```sh
xdelta3 -d -s "Summon Night 3 (Japan).iso" "SN3-English-v0.1.35.xdelta" "Summon Night 3 English v0.1.35.iso"
```

The source must be the unpacked Japanese ISO, not a ZIP, CSO, CHD or previous
English image. Source size: **1,658,159,104 bytes**. Source SHA-256:
`00b9fe052e7f516a2975cb3e625682640ec17edb7bd23f3a785f6c73d4bbefda`.
Check `README-v0.1.35.txt` for the target hash. Do not disable checksum checks.

### What changed in v0.1.35

- Translated **24 additional menu-help groups**, including the separate
  in-battle Summon Index description and related shopping, Gallery, training,
  favorites, loading, minigame and retreat descriptions.
- Translated **39 generic enemy labels across 164 references**, including
  Pirate, Bandit, Assassin, Outlaw, Ghost Captain and Beastfolk. Longer names
  use compact labels for the native unit-name field.
- Checked all **58 references** in the menu-help group for English text and
  the safe two-line layout.
- Retained the earlier story, battle-dialogue, menu artwork, VWF, save-name
  display and crash fixes. The original game image is not included.

This is the project's first GitHub release; earlier numbered builds are
documented in `CHANGELOG.md`. `CHANGELOG-v0.1.35.txt` includes that history.
Download hashes are in `SHA1SUMS-v0.1.35.txt` and `SHA256SUMS-v0.1.35.txt`.

### Testing and remaining limits

The delta was applied to the clean Japanese source and matched the complete
tested v0.1.35 output hash. Build checks verify all 23 archive indexes and
5,728 unchanged resources, plus source identities, menu lengths and name
references.

Runtime checks used **PPSSPP 1.20.4 software rendering**, a fresh launch and
an in-game Suspend save from v0.1.34. The first battle's Summon Index description,
Pirate compact card, full status screen and return to battle were verified.
Other new entries received source and structural checks rather than individual
in-game visits. This is not a complete eight-chapter route playthrough.

Later chapters, some classes, equipment text, named creatures and graphical
labels remain untranslated or untested. Original PSP hardware has not been
tested. Use an in-game save when changing builds: emulator save states retain
the previous executable and resources.

### How it was translated

This is **AI-assisted translation**, drafted and reviewed with language models
under the maintainer's direction. Agent reviews are not human proofreading.
No audited total of human-reviewed lines is available. Character spellings
follow the project's user-selected reference and versioned glossary.

### Source code

GitHub's **Source code (zip)** archive is the repository snapshot at this tag:
English targets, tools, glossary, documentation and UI evidence. It does not
contain a playable game image. Use the `.xdelta` asset to patch the game.
The incremental builders still require locally supplied game data, dependencies
and historical intermediate outputs; a clean clone is not yet a one-command
build distribution.
