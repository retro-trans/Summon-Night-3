English translation test build for **Summon Night 3** on PSP, Japanese release
**NPJH50380**. This is an incomplete translation; earlier story and battle
coverage through Chapter 8 still has the limitations documented in the repository.

### Apply

Use [Retro Trans](https://github.com/retro-trans/retro-trans-tools) **0.3.1 or later**.
Refresh its catalog, select your clean Japanese ISO or verified English v0.1.35
ISO, and choose **Latest** or **0.1.36** in Automatic mode.

Manual Apply xdelta and [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher)
can also apply the matching patch below. Keep checksum verification enabled.

| Source image | Patch |
|---|---|
| Clean Japanese PSP ISO, NPJH50380 | `SN3-English-v0.1.36.xdelta` |
| English v0.1.35 ISO | `SN3-English-v0.1.35-to-v0.1.36.xdelta` |

The Japanese source is **1,658,159,104 bytes**, SHA-256
`00b9fe052e7f516a2975cb3e625682640ec17edb7bd23f3a785f6c73d4bbefda`.
The v0.1.35 source SHA-256 is
`01ae84776c9ad3d5e57bdb6f35291f79b0377f9c1322636703cd6b8544c062db`.
All source, target and patch identities are recorded in `BUILD-MANIFEST.json`.

Use unpacked ISOs for the verified workflow. Start the new image fresh and
load an in-game save; emulator save states retain old executable/resource data.

### What changed in v0.1.36

- Translated all **22 tutorial title records** in the Gallery list as
  **Review Basics**, retaining proportional letter spacing.
- Shortened **Weapons & Range** to prevent overlap with the Page column.
- Translated the **Illustrations** and **Sound** headings and the **View**,
  **Sound Mode**, **Exit**, **Play** and **Artwork** controls.
- Preserved locked entries, unrelated graphics and the existing executable.

### Testing and remaining limits

Checked the list, column fit, scrolling and mode switching in a fresh
PPSSPP 1.20.4 software-rendered launch using copied in-game system data.
The builder also checks 23 archive indexes, both resident table copies,
5,727 unchanged resources and pointer/layout bounds.

Both full and upgrade patches are built with Retro Trans and round-trip
checked against the complete target hash. See `VALIDATION.json`.

This update covers the Gallery list and its paired controls. Gallery tutorial
page artwork, music titles and the parent Gallery menu are not translated by
this update. The translation is still incomplete and has not received a full
route playthrough or PSP hardware testing. AI-assisted drafting and author
review do not represent human proofreading totals.
