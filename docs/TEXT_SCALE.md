# Text scale estimate, 2026-09-27

The recognized script index contains 153,524 string occurrences across 327
text-bearing resources, with 49,607 distinct source strings. Of those, 151,840
occurrences and 49,545 distinct strings contain Japanese. The interface-table
inventory separately contains 3,633 strings. These inventories can overlap;
do not add them into a claimed number of unique dialogue lines. Text embedded
in artwork is not fully counted here.

An entry is a fragment, not necessarily a sentence or dialogue box. Alternate
branches and shared script libraries account for many repeated entries. The
compiled reference order also differs from the order in a single playthrough.

A preliminary sample of 4,545 translated fragments contained 13,908 English
words for approximately 36,452 Japanese source characters. Applying that ratio
to the approximately 477,354 characters in distinct Japanese strings suggests
about 182,000 English words. A broad working estimate is 180,000–220,000 words
of distinct translated script text. This is an extrapolation, not a measured
full-game English word count or the amount read in one playthrough. Short
repeated fragments can require different translations in different contexts.

For scale, a commonly cited count for the three *Lord of the Rings* books is
481,103 words, including 187,790 for *The Fellowship of the Ring*. Counts vary
with editions and counting methods. The game's distinct-text estimate is
roughly 37–46% of that trilogy, approximately one *Fellowship*-sized book.
Source: https://www.wordcountertool.net/word-count-popular-books
