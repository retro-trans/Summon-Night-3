# Skill help and startup notice, local build 0.1.70

The reported Max MP help means maximum MP rises by ten for each skill level.
The immutable 0.1.69 table already contains `Max MP +10/level.`; 0.1.70 retains
that help and the other eleven stat and affinity-resistance descriptions.

This pass translates twelve remaining native fragments in the equipment and
transformation help formatter: critical-hit instant defeat, counterattack and
ailment chances, piercing, vertical reach, Snipe, distance attenuation, forms,
and remaining uses. Full meanings are retained beside compact display text.
`Uses left: <count>` replaces the source prefix and count suffix together.
Snipe follows the existing English terminology. Vertical range means elevation.

The startup notice is texture 02:00025/00000. The built-in imagegen tool replaces
Japanese lettering with the reviewed English notice, keeping the original
ornate-frame design and parchment layout. The generated image is resampled to
480 by 272 and encoded with the unchanged native palette and sprite geometry.
The final prompt is recorded in the image generation tool call in this chat:
preserve the frame/background, replace the heading with Notice and insert the
four-line distribution/download notice and cooperation footer. The sibling
publisher logos are already English and remain unchanged.

Original native text pools, source tables, numeric records, prior hooks and
published snapshots are preserved. Only references to the twelve new native
fragments and the notice's pixels change. No new release is published.

Validation executes the actual skill type switch, string builder and line
writer, with record lookup, integer conversion and elementary memory operations
as boundary stubs. It tests thirteen equipment IDs, transformation with and
without a three-digit remaining-use count, and twelve retained stat helps.
Native rows remain within 27 cells and combined help within 54 cells.
Fresh-boot and regression evidence is saved beside the test ISO.
